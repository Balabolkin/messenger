# Elph Messenger (Rocket.Chat Client)

Клиент мессенджера под Android на основе дизайна Elph и REST/WebSocket API Rocket.Chat.

## Особенности проекта (Features)

*   **Авторизация и профиль:** Авторизация по логину и паролю с кэшированием токенов безопасности. Экран профиля с возможностью безопасного выхода (с полной очисткой локальной базы данных и Shared Preferences).
*   **Список чатов:**
    *   Скроллящийся список чатов с постраничной пагинацией.
    *   Отображение аватарок (включая приватные аватарки через защищенный HTTPS-прокси с прокидыванием сессионных токенов авторизации).
    *   Реалтайм обновление последних сообщений через WebSocket (DDP протокол).
    *   Индикаторы статуса прочтения сообщений (серая галочка — доставлено на сервер, двойная зеленая галочка — прочитано собеседником).
*   **Экран переписки (Чат):**
    *   Динамическое отображение количества участников группы/канала на верхней панели (загружается через API `rooms.info`).
    *   Двухэтапная отправка медиафайлов: загрузка на сервер через эндпоинт `rooms.media` и последующая привязка к сообщению через `chat.postMessage`.
    *   Автоматическое сжатие изображений: если файл превышает лимит сервера (`FileUpload_MaxFileSize` — 5 МБ), он автоматически масштабируется и сжимается до допустимого размера, чтобы избежать ошибок загрузки.
    *   Синхронизация статуса прочтения сообщений при входе в чат и получении новых сообщений (очистка бейджей непрочитанных).
    *   Сохранение WebSocket-соединения при переходах между экранами приложения, автоматическое переподключение и повторная авторизация в сокете при возобновлении работы приложения.

## Стек технологий (Tech Stack)

*   **UI:** Jetpack Compose, Material 3
*   **Архитектура:** MVVM (Model-View-ViewModel) + Clean Architecture
*   **Навигация:** Type-safe Jetpack Navigation Compose
*   **Асинхронность:** Kotlin Coroutines & Flow
*   **Внедрение зависимостей (DI):** Dagger Hilt
*   **Локальная база данных:** Room DB (кэширование чатов и сообщений для работы офлайн)
*   **Сетевой слой:** Ktor Client (для REST API) + OkHttp (для WebSocket DDP-соединения и multipart-загрузки файлов)
*   **Загрузка изображений:** Coil (с поддержкой SVG-декодера для аватарок)
*   **Хранение сессий:** Jetpack DataStore Preferences

## Запуск проекта

1.  **Требования:**
    *   Android Studio Ladybug или новее.
    *   JDK 17.
    *   Android SDK 37 (compileSdk 37, minSdk 24).
2.  **Сборка проекта:**
    Выполните в терминале для проверки компиляции:
    ```powershell
    ./gradlew.bat compileDebugKotlin
    ```
3.  **Сборка APK:**
    ```powershell
    ./gradlew.bat assembleDebug
    ```
